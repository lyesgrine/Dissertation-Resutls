# Dissertation-Resutls
This repository is for storing my dissertation resutls/topologies/screenshots

Each folder will have one topology with:
- EVE-NG export file
- Topology screenshot 
- Video recording of the experiment (manual and automatic summary of area 1)
- ABR router show commands output file 
- Area 0 router show commands output file



The show commands collected are: (before and after each summary method)
- show running (on ABR)
- show ip ospf route / show ip route
- show ip ospf database
- show ip ospf database database-summary

- ping all summarized addresses/routes
